returned temporary failure in name resolution; the public web retrieval tool also
could not access the catalog. Do not bypass network controls or silently replace
the failed observations. The original three-cycle acquisition remains bounded.

census books and all twelve AMS-007 book observations. This is reused development
evidence, not fresh or independent validation. Filter programs using AMS-009's
admission predicate at each original book receipt time. Include every qualifying
observed market; do not select based on the new scenario results.

catalog, using that catalog's receipt time. This assesses catalog coverage and
category concentration only, not whether unobserved books offered opportunities.

per-event dependence. Repeated observations of a pool are never added as income.

claim. The new acquisition's zero selected markets after a failed catalog must
