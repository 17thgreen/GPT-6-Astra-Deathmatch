# Next study: structure first, then speed

This is a research queue, not a preregistration of a profitable strategy. A concrete
instrument panel and its fee/settlement proof must be frozen before economic scoring.

1. Build the candidate panel from currently open contracts, joined to the incentive
   sample and series rules. Do not infer lack of incentives from absence in a capped
   listing. Classify by mechanism and ground-truth source across all categories.
2. First screen same-source, same-observation-time nested thresholds. Prove the
   payoff relationship from contract rules, including cancellation exceptions. If
   A implies B, buying YES B and NO A has a $1 floor only when those terms align.
   Record executable multi-level cost plus both fees; mark sequential REST books
   as asynchronous observations, never a simultaneously lockable arbitrage.
3. Independently investigate scheduled official releases and external reference
   price moves. Measure when information reaches our process, when the venue book
   changes, and whether excess value remains after achievable arrival delay.
   Binary thresholds need conditional probabilities; a spot change is not a
   binary fair-value change of the same magnitude. Keep perps separate.
4. Join incentives as an explanatory variable for quote size/replenishment. Test
   against matched unincentivized periods and retain failed signals. Reward pools
   are not account entitlements. Fee rebates remain zero until verified.

The demo key enables engineering work: sequence-gap handling, snapshot application,
reconnect recovery and simulated order lifecycle. It does not supply production
stream access or validate a latency advantage. Production stream capture needs
separate production credentials; no order permission is implied by research.

Before any speed claim: distinguish decision time, network round trip, exchange
acknowledgement, and actual fills. Test 10–5000 ms delay sensitivity from a complete
receipt stream. A disappearing quote is not our execution. Missing second legs,
shared depth consumption and unresolved inventory must reduce or block the score.

Current priority judgment: threshold consistency and official-source propagation
are attractive places to look because the information/payoff relationships can be
specified precisely. This is not evidence they outperform crypto, sports or perps.
The fastest-taker hypothesis remains open; this discovery run cannot accept or
reject it. No paid feed, infrastructure upgrade or live strategy is selected.
