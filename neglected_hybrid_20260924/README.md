# Neglected-market hybrid forecasting

NH-001 implements strategy 1 from the September 24 research review: compare an
independent specialist forecast, a market forecast and fixed hybrids, then test
whether any advantage survives a transparent trading-cost screen.

Start with [SPEC.md](SPEC.md). No historical scores have been calculated at this
initial checkpoint. Data admission is part of the experiment, not a formality.
No background service or order-capable bot is being deployed.
