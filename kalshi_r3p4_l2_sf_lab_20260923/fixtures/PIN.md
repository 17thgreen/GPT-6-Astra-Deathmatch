# Synthetic ladder

`synthetic_two_sided_ladder.json` is a code-path stand-in. Source is
`synthetic_schema_standin`. Book ids start with `synthetic:`. Both books
use the same ten-level ladder so the arm, not the category label, is the
knob.

It is not a Kalshi GET, not the conductor panel, and not production depth.
Scorecard fields stay null. The live_get order books are the pinned files
beside this lab, not this ladder.
